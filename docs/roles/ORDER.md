# ORDER 역할

## 책임과 접근 범위

조달계획과 조달계약을 근거로 발주를 등록하고 진행상태·검수·차트를 관리한다. `/order/**`는 ORDER와 ADMIN에 명시적으로 허용된다.

## 업무 절차

1. 상태가 `진행중`인 조달계획을 선택한다.
2. 연결할 조달계약과 자재·공급사·단가 정보를 확인한다.
3. 발주코드, 수량, 발주일, 납기일, 담당자와 비고를 입력한다.
4. 발주 목록과 상세에서 상태 및 납기를 관리한다.
5. 진척검수 화면에서 차수별 검수일·상태·비고를 기록한다.
6. 검수 완료 시 발주 상태를 `검수완료`로 변경한다.
7. 발주 완료 처리 시 완료 수량을 조달계획 필요량과 비교한다.
8. 충족하면 연관 조달계획을 `계획완료`로 전환한다.
9. 발주 차트에서 자재·연도·상태별 월간 수량을 확인한다.

## 관련 데이터

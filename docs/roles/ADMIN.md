# ADMIN 역할

## 책임과 접근 범위

모든 명시적 역할 제한을 통과하는 운영 관리자다. 계정·권한 관리와 전 업무 흐름의 장애 처리 및 데이터 정합성 확인을 담당한다.

## 업무 절차

1. 직원 목록과 상세 정보를 확인한다.
2. 직원 권한 화면에서 업무에 맞는 역할을 부여한다.
3. 비활성/퇴사 계정을 삭제 상태로 변경한다.
4. 기준정보(자재·제품·공급사·고객사)를 점검한다.
5. 제품계약부터 생산·조달·발주·입고까지 상태 정체 구간을 확인한다.
6. 게시글 수정·삭제와 운영상 예외를 처리한다.
7. DB 관계와 업로드 파일(UUID/파일명)의 정합성을 점검한다.

## 관련 데이터

전체 테이블. 특히 `employee`, `employee_role_set`, 각 업무 엔티티의 상태 필드와 이미지 테이블을 중점 관리한다.

## 구현상 주의점

- 역할은 단일 값으로 운용되는 화면 로직이 많지만 DB 모델은 역할 집합이다.
- 비밀번호는 BCrypt 해시이므로 조회가 아니라 재설정 방식으로 복구한다.
- 업무 상태는 화면·검색·서비스의 표준 문자열을 사용하고, 직접 DB 수정은 마지막 수단으로 사용한다.

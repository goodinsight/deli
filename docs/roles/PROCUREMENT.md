# PROCUREMENT 역할

## 책임과 접근 범위

생산에 필요한 자재의 조달계획과 공급사 기반 조달계약을 담당한다. 두 조달 URL은 PROCUREMENT와 ADMIN에 명시적으로 허용된다.

## 업무 절차

1. 생산계획을 조회해 제품, 생산수량, 납기와 공정을 확인한다.
2. 제품별 자재소요량과 대상 자재를 선택한다.
3. 필요 수량과 조달 납기일을 계산해 조달계획을 등록한다.
4. 조달계획 상태를 `진행중`으로 관리한다.
5. 진행 중인 조달계획과 적합한 공급사를 선택한다.
6. 공급단가, 조달수량, 계약일, 조건을 입력해 조달계약을 등록한다.
7. 계약 상태를 `조달계약협상중 → 발주진행중 → 조달완료`로 관리하거나 파기한다.
8. 조달계획 상세에서 연결된 발주 목록과 누적 진행을 확인한다.

## 관련 데이터

- `material_procurement_planning`
- `material_procurement_contract`, `material_procurement_chart`
- `production_planning`, `material_requirements_list`, `materials`
- `cooperator_supplier`, `orders`

## 다음 단계

확정된 조달계획과 계약은 ORDER 역할의 발주 등록 입력이 된다.

## 매입 청구 확정

자재조달계약 상세의 **매입 청구 등록·내역**에서 PROCUREMENT 또는 ADMIN이 공급사 청구번호, 청구일, 지급 예정일, 원화 금액을 확인하고 확정한다. 지급 예정일은 청구일 당일 또는 이후로 입력한다. 입고 횟수와 관계없이 확정한 청구만 계약 미지급액에 합산한다. 같은 공급사의 청구번호는 계약 전체에서 한 번 사용하며, 한 계약에 서로 다른 청구번호를 여러 건 등록할 수 있다.

각 청구 행에서 실제 지급액을 기록하면 청구별·계약별 미지급액이 줄어든다. 잘못 기록한 지급은 사유를 입력해 해당 지급 전액을 취소한 뒤 올바른 금액을 새 지급으로 등록한다. 원지급의 금액·처리자·시각과 취소의 사유·처리자·시각은 함께 남는다.

**자재조달계약 목록 → 공급사별 미지급·연체 현황**에서 공급사별 미지급 합계와 연체액을 확인한다. 한국 날짜 기준 지급 예정일이 지난 청구의 남은 금액만 연체액에 포함한다. 공급사를 펼쳐 청구번호 또는 조달계약을 선택하면 원기록으로 이동한다. 전액 지급한 청구는 제외되며, 지급 기록을 취소해 잔액이 생기면 다시 표시된다.

지급 이력이 없는 청구는 **매입 청구 등록·내역 → 청구 취소**에서 사유를 입력해 취소한다. 계약 및 공급사 미지급·연체 합계에서 해당 잔액이 제외되며, 원래 청구번호·금액과 취소 사유·처리자·시각은 계약의 청구 내역에 남는다. 지급 기록을 정정한 이력이 있는 청구도 이 경로에서는 취소할 수 없다.

실제 지급 후 공급사가 청구를 철회하면 지급 행에서 **공급사 환급** 또는 **대체 정산**을 선택해 해당 원지급 전액의 처리 근거를 기록한다. 실지급액이 0원이 되면 실제 내역을 대조하고 사유를 입력해 **대조 후 청구 취소**를 선택한다. 입력 오류 취소와 실제 환급·정산 기록은 구분되며, 원지급과 증빙 참조·확인자·확인 시각은 조회할 수 있다.

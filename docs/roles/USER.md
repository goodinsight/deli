# USER 역할

## 책임과 접근 범위

일반 사용자를 위한 기본 역할이다. 명시적으로 허용된 업무는 게시판 조회·등록·상세이며, 게시글 수정·삭제는 ADMIN으로 제한된다.

## 업무 절차

1. 회원가입 후 로그인한다.
2. 게시판 목록을 조회하고 조건으로 검색한다.
3. 업무 공유가 필요하면 글과 이미지를 등록한다.
4. 상세 화면에서 댓글을 조회·등록·수정·삭제한다.
5. 업무 카테고리 접근이 필요하면 ADMIN에게 역할 변경을 요청한다.

## 관련 데이터

- `employee`, `employee_role_set`
- `board`, `board_image`, `reply`

## 접근 범위

USER에게는 게시판 메뉴만 노출된다. 업무 URL은 역할별 서버 권한 검사로 차단되므로 추가 업무가 필요하면 ADMIN이 해당 역할을 부여해야 한다.

# SUPPLIER 역할

## 책임과 접근 범위

자재 공급사 기준정보를 관리하고 조달 담당자가 계약할 수 있는 파트너 정보를 유지한다.

## 업무 절차

1. 공급사의 사업자번호, 회사명, 대표자, 주소, 이메일, 연락처를 등록한다.
2. 공급사 상태를 `계약전`, `계약중`, `계약종료`, `계약파기` 등으로 관리한다.
3. 공급사 목록과 상세에서 정보를 검증하고 수정한다.
4. PROCUREMENT가 조달계약을 만들 때 선택할 수 있도록 최신 상태를 유지한다.
5. 계약 종료 또는 파기된 공급사를 조달 대상에서 구분한다.

## 관련 데이터

- `cooperator_supplier`
- `material_procurement_contract`
- `document_file`

## 접근 범위

협력사 URL은 SUPPLIER/PROCUREMENT/ADMIN으로 제한된다. PROCUREMENT는 조달계약 대상 공급사를 선택하고 관리하기 위해 함께 접근한다.

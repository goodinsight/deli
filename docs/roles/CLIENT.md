# CLIENT 역할

## 책임과 접근 범위

고객사와 제품 중심의 업무를 담당하는 역할이다. 보안 설정상 `/product/**` 접근 권한이 명시되어 있다.

## 업무 절차

1. 고객 요구에 맞는 제품 기준정보를 조회한다.
2. 고객사 정보를 확인하거나 등록·수정한다.
3. 고객사, 제품, 계약수량, 계약일, 납기, 견적을 연결해 제품계약을 등록한다.
4. 제품계약 상태를 `자재검토중`, `자재조달중`, `자재입고중`, `제품생산중`, 완료/파기 상태로 관리한다.
5. 후속 생산계획과 납기 진행상태를 확인한다.

## 관련 데이터

- `cooperator_client`
- `products`, `product_contract`
- `production_planning`

## 접근 범위

클라이언트와 제품계약 URL은 CLIENT/ADMIN으로 제한된다. 제품 기본정보는 계약 대상 조회를 위해 CLIENT에게도 허용된다.

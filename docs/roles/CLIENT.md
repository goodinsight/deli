# CLIENT 역할

## 책임과 접근 범위

고객사와 제품 중심의 업무를 담당하는 역할이다. 보안 설정상 `/product/**` 접근 권한이 명시되어 있다.

## 업무 절차

1. 고객 요구에 맞는 제품 기준정보를 조회한다.
2. 고객사 정보를 확인하거나 등록·수정한다.
3. 고객사, 제품, 계약수량, 계약일, 납기, 견적을 연결해 제품계약을 등록한다.
4. 제품계약 상태를 `자재검토중`, `자재조달중`, `자재입고중`, `제품생산중`, 완료/파기 상태로 관리한다.
5. 후속 생산계획과 납기 진행상태를 확인한다.

## 관련 데이터

- `cooperator_client`
- `products`, `product_contract`
- `production_planning`

## 접근 범위

클라이언트와 제품계약 URL은 CLIENT/ADMIN으로 제한된다. 제품 기본정보는 계약 대상 조회를 위해 CLIENT에게도 허용된다.

## 고객사 상담 이력

고객사 목록에서 회사명을 선택한 뒤 상세 화면의 **상담 이력**에서 상담 일시, 연락 방식, 내용을 입력한다.
작성자는 로그인 계정으로 기록되며, CLIENT와 ADMIN은 해당 고객사의 이력을 최신 상담부터 확인할 수 있다.
상담 이력이 있는 고객사의 삭제 요청은 상세 화면으로 돌아가며 이력을 보존한다.

상담별로 후속 연락이 필요하면 담당자와 예정일을 지정한다. 담당자는 고객사 목록의 **내 후속 연락**에서 기한 경과·오늘·예정 항목을 예정일순으로 확인한다. 날짜 구분은 한국 시간을 기준으로 한다.
고객사명을 누르면 해당 상담으로 이동한다. 지정된 담당자가 처리 결과를 남겨 완료하면 내 목록에서 빠지고, 고객사 상세에는 담당자·예정일·결과가 남는다.

상담의 **견적 작성·이력**에서 제품·수량·단가(원)·납기를 입력해 견적을 저장한다. 상담 하나에서 단일 제품 견적의 버전을 관리한다.
CLIENT와 ADMIN이 작성할 수 있으며, ADMIN이 최신 버전을 승인한다. 수정 시에는 새 버전을 저장하고 다시 승인한다. 이전 버전의 제품명, 금액, 납기, 작성자와 승인 기록은 보존된다.

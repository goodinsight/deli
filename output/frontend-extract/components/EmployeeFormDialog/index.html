export 함수의 구조 분해 입력값

  • I ← Do: controller
  • M ← Lo: member, size
  • N ← te: controller, icon, label, name, unit, decimal, max
  • S ← H: controller, icon, label, name, options, emptyLabel, numeric
  • T ← N: controller, icon, label, name, maxLength, placeholder, inputMode, wide, full, rowStart, multiline, normalize, date, format
  • b ← Xs: controller, units, members, docked
  • h ← we: controller, icon, label, name
  • n ← Zs: employee, invite
  • p ← Us: orgSeq, onChanged
